# ADR-0002: Разделение кода на index.html, styles.css и app.js

- **Статус:** принято
- **Дата:** 2026-11-04
- **Заменяет:** раздел «Стек» в [ADR-0001](0001-mvp-architecture.md)

## Контекст

По ADR-0001 весь код MVP лежит в одном `index.html`: стили в `<style>`,
логика в `<script>`. При пошаговой реализации такой файл быстро вырастает до
сотен строк, в нём смешаны разметка, стили и логика, а дифы читать неудобно.

## Решение

Код разделён на три файла в корне репозитория:

- `index.html` — разметка листа;
- `styles.css` — стили, подключаются через `<link>`;
- `app.js` — логика, подключается обычным `<script defer>`.

Сборки, фреймворков и зависимостей по-прежнему нет. Страница открывается
двойным кликом из файловой системы.

`app.js` — обычный скрипт, а не ES-модуль: браузеры блокируют загрузку модулей
по протоколу `file://`.

## Отклонённые варианты

- **Всё в одном `index.html`.** Нет отдельных файлов, но разметка, стили
  и логика перемешаны, а файл трудно читать и ревьюить.
- **ES-модули (`<script type="module">`).** Позволили бы разбить логику на
  несколько файлов с `import`, но не работают при открытии страницы из
  файловой системы.

## Последствия

- Каждое изменение затрагивает файл одного типа: разметку, стили или логику.
- Весь JavaScript пока в одном файле. Если он станет слишком большим, это
  сигнал к переходу на Vite + React + TypeScript из точек роста ADR-0001.
- Для публикации нужно выложить три файла вместо одного.
