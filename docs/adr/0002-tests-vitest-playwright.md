# ADR-0002: Тесты на Vitest и Playwright

- **Статус:** предложено
- **Дата:** 2026-11-08

## Контекст

ADR-0001 запрещает сборку и npm-зависимости. План MVP предполагает только
ручную проверку в браузере. Логика скриптов растёт, а ручная проверка
не ловит регрессии. Страницу нужно проверять в разных браузерах
и на телефоне.

## Решение

- Unit-тесты на Vitest в jsdom проверяют скрипты из `assets/js`
  по отдельности.
- E2E-тесты на Playwright проверяют страницу целиком в настоящих браузерах.
- Инструменты тестов — только `devDependencies`. Страница по-прежнему
  не зависит от npm и открывается двойным кликом.
- Тесты пишем на TypeScript. Код страницы остаётся на JavaScript с JSDoc.
- Скрипты страницы остаются обычными, не ES-модулями. Unit-тесты выполняют
  их через собственный загрузчик.
- E2E-тесты работают со страницей через page object.
- Типы тестов проверяет TypeScript по отдельным конфигам.
- Все проверки запускаются одной командой локально и в CI.

## Отклонённые варианты

- **Запуск через `npx` без `package.json`.** Vitest ищет jsdom и свой конфиг
  в папке проекта. Без локальной установки запуск ненадёжен.
- **Перевод скриптов на ES-модули.** Модули не загружаются по `file://`.
- **Экспорт для Node через `module.exports`.** В рабочем коде появится ветка
  только для тестов.
- **Тесты на JavaScript с JSDoc.** Ограничение `file://` на тесты
  не действует. Типы в JSDoc длиннее, чем в TypeScript.
- **Перевод кода страницы на TypeScript.** Понадобится сборка. ADR-0001
  откладывает это до перехода на Vite + React + TypeScript.
- **Только unit-тесты.** jsdom не строит раскладку и не проверяет страницу
  целиком.

## Последствия

- Для тестов нужен `npm install`. Для e2e-тестов — ещё браузеры Playwright.
- Запрет на npm-зависимости из ADR-0001 касается кода страницы. На инструменты
  разработки он не распространяется.
- В репозитории два языка. Правила для каждого описаны в `AGENTS.md`.
- Vitest и Playwright не проверяют типы. Это делает отдельная проверка
  TypeScript.
- В `index.html` появляются атрибуты, которые нужны только тестам.
- E2E-тесты открывают страницу по HTTP. Открытие по `file://` они
  не проверяют.
- При переходе на Vite + React + TypeScript тесты переносятся почти без
  изменений.
