# AGENTS.md

Инструкции для AI-агентов, которые работают с этим репозиторием.

## О проекте

Веб-страница с листом персонажа (Champion Sheet) настольной ролевой игры
Twilight Sword. Пользователь заполняет лист в браузере, данные сохраняются
локально.

Архитектурные решения описаны в [docs/adr](docs/adr). Перед изменениями прочитай
их; если изменение противоречит принятому ADR — сначала предложи новый ADR.

## Ограничения MVP

Подробности и обоснование — в [ADR-0001](docs/adr/0001-mvp-architecture.md).

- **Один `index.html`** с CSS и чистым JavaScript. Без сборки, фреймворков,
  npm-зависимостей и CDN. Страница должна открываться двойным кликом из
  файловой системы.
- **Хранение — `localStorage`.** Состояние листа — один JSON-объект под одним
  ключом, с полем версии схемы. Сохранение при каждом изменении, восстановление
  при загрузке.
- **Модель данных и хранилище отделены от работы с DOM**, чтобы потом
  перенести логику на React.
- **Адаптивная вёрстка:** на десктопе раскладка повторяет бумажный лист,
  на телефоне карточки идут в одну колонку.
- **Не добавляй без отдельного решения** то, что записано как точки роста:
  Vite + React + TypeScript, экспорт и импорт JSON, экспорт в PDF.

## Авторские права

- Не используй графику издателя игры: логотип, эмблемы, иконки состояний,
  орнаментные рамки, фоновые узоры, рисунки. Оформление — только собственное:
  CSS, текст, простые собственные иконки.
- Не добавляй в репозиторий официальный PDF листа персонажа и другие материалы
  издателя. Репозиторий публичный и распространяется под лицензией MIT.
- Названия полей и игровые термины («Сила», «Зины», «Рана») использовать можно.

## Код

- Не пиши комментарии в коде. Делай код самодокументируемым: понятные имена,
  отдельные функции с говорящими названиями, именованные константы вместо
  магических значений.
- Тексты интерфейса — на русском.

## Git

- **Ветки:** `тип/краткое-описание` латиницей в kebab-case, например
  `feat/stats-block`, `docs/adr-0002-json-export`.
- **Коммиты:** [Conventional Commits](https://www.conventionalcommits.org/)
  на английском. Заголовок в повелительном наклонении, до 72 символов, без точки
  в конце. В теле — зачем сделано изменение.
- Типы: `feat`, `fix`, `docs`, `refactor`, `style`, `test`, `chore`, `ci`.
- Не коммить, не пушь и не создавай pull request без явного подтверждения
  пользователя.

## Документация

- Документация и ADR пишутся на русском.
- Новый ADR — файл `docs/adr/NNNN-краткое-название.md` со следующим номером
  и разделами: статус, дата, контекст, решение, отклонённые варианты,
  последствия.
